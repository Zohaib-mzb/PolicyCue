# PolicyLens

Evidence-first AI for understanding company policies, terms, and agreements.

PolicyLens allows users to provide policy URLs, company websites, PDFs, or long-form text and ask natural-language questions about what those documents actually say.

## Core idea

Instead of simply summarizing documents, PolicyLens retrieves relevant evidence and uses AI to provide grounded, explainable answers.

## Planned capabilities

- Policy URL ingestion
- Company website policy discovery
- PDF ingestion
- Long-text ingestion
- RAG-based question answering
- Evidence-backed answers
- Source citations
- Policy comparison
- Logical reasoning over multiple policy sections
- Security-focused document processing

## Architecture

React → FastAPI → RAG → Vector Database → Gemini
